Cómo desplegar este Dashboard en la Web

Este dashboard está diseñado con arquitectura estática pura (HTML, CSS y JS con datos embebidos). No requiere pagar por servidores, ni configurar Node.js ni bases de datos.

🐙

Opción 1: GitHub Pages (Recomendado)

Toma 2 minutos
  1. Crea un repositorio en GitHub (ej: taller-estadistica).
  2. Sube los archivos de esta carpeta: index.html, datos_dashboard.js, y opcionalmente clientes_final.csv.
  3. Ve a Settings → Pages en tu repositorio de GitHub.
  4. En Branch selecciona main (o master) y carpeta / (root), luego haz clic en Save.
  5. ¡Listo! Tu sitio quedará publicado en: https://tu-usuario.github.io/taller-estadistica/
⚡

Opción 2: Netlify Drop / Vercel (Arrastrar y Soltar)

Toma 30 segundos
  1. Entra a app.netlify.com/drop.
  2. Arrastra toda la carpeta del taller (Taller final Estadistica) dentro del recuadro.
  3. Netlify te generará un enlace público inmediato con HTTPS gratis (ej: https://restaurantes-usa.netlify.app).
💻

Opción 3: Probar Localmente en tu Computador

Solo haz doble clic sobre el archivo index.html en tu explorador de archivos de Windows y se abrirá en tu navegador de inmediato.
